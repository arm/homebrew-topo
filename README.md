# homebrew-topo

Homebrew tap for [topo](https://github.com/arm/topo) — compose, parameterize, and deploy containerized examples for Arm hardware.

## Install

```sh
brew tap Arm/topo
brew install topo
```

### From source (HEAD)

```sh
brew install --HEAD topo
```

This clones the `main` branch and builds with Go.
